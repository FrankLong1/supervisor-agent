# Supervisor console concepts

Open any of these files directly in a browser; they are standalone static prototypes with illustrative data only.

1. `01-morning-brief.html` — the 30-second “what happened while I slept?” view.
2. `02-operations-queue.html` — an active queue and health overview.
3. `03-task-audit.html` — a single task’s durable evidence and controlled operator actions.

They intentionally model the supervisor as a safety monitor, not a general-purpose agent orchestrator: no card drag/drop, no retry button, and no UI path that can silently send a reply.
